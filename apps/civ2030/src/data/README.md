# /src/data

Contenu data-driven du jeu : technologies, unités, bâtiments, événements narratifs,
archétypes d'IA. Des modules TypeScript déclaratifs (constantes typées), **sans logique** :
l'engine consomme ces tables, jamais l'inverse.

Remplissage progressif : bâtiments (Phase 2), unités (Phase 3), tech tree (Phase 4),
personnalités IA (Phase 5), événements (Phase 6).
